# 🎵 YouTube Toolkit

Professional command-line toolkit built with Python and yt-dlp for downloading
YouTube videos, audio, and playlists while providing utilities to organize
large offline music libraries.

------------------------------------------------------------

✨ Features

✔ Download videos in highest quality
✔ Convert videos to MP3
✔ Download complete playlists
✔ Automatically extract audio using FFmpeg
✔ Detect duplicate songs using SHA-256 hashing
✔ Remove duplicate files safely
✔ Remove playlist numbering from filenames
✔ Continue downloading even if some videos fail
✔ Android client support for improved compatibility
✔ Works with Windows, Linux and macOS
