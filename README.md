# 🎵 YouTube Toolkit

A collection of Python utilities for downloading YouTube videos, MP3s, playlists, and organizing your music library using **yt-dlp**.

## Features

- 🎥 Download YouTube videos
- 🎵 Download single videos as MP3
- 📂 Download entire playlists as MP3
- 🔢 Remove playlist numbering from filenames
- 🔍 Detect duplicate songs using SHA-256 hashes
- 🗑 Remove duplicate songs automatically
- ⚡ Powered by yt-dlp and FFmpeg

---

## Project Structure

```
.
├── yt_downloaders.py      # Interactive downloader
├── download_mp3.py        # Download a single MP3
├── clean_music.py         # Remove playlist numbering
├── what.py                # Find duplicate songs
├── delete.py              # Delete duplicate songs
├── README.md
└── .gitignore
```

---

## Requirements

- Python 3.10+
- yt-dlp
- FFmpeg

Install dependencies:

```bash
pip install yt-dlp mutagen
```

Install FFmpeg and ensure it is added to your system PATH.

---

## Usage

### Interactive Downloader

```bash
python yt_downloaders.py
```

Menu:

```
1. Download Video
2. Download MP3
3. Download Playlist MP3
4. Exit
```

---

### Download a Single MP3

```bash
python download_mp3.py
```

Paste the YouTube URL when prompted.

---

### Remove Playlist Numbers

Example:

Before

```
0001 - Song Name.mp3
0015 - Another Song.mp3
```

After

```
Song Name.mp3
Another Song.mp3
```

Run:

```bash
python clean_music.py
```

---

### Find Duplicate Songs

Uses SHA-256 hashing to compare file contents.

```bash
python what.py
```

Example:

```
Duplicate:
  Song (1).mp3
  Same as: Song.mp3
```

---

### Delete Duplicate Songs

After verifying duplicates:

```bash
python delete.py
```

The script deletes duplicate files while keeping one copy.

---

## Notes

- The playlist downloader is optimized for regular YouTube playlists (`PL...`).
- YouTube Mix playlists (`RD...`) may not download reliably because they are dynamically generated by YouTube.
- If YouTube requests authentication, export your cookies and place them in a local `cookies.txt` file (do **not** commit it to GitHub).
